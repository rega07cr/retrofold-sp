Pubblicare su GitHub (2 min)

  1. Crea repo retrofold-sp su GitHub.
  2. git init && git add . && git commit -m "RetroFold SP" && git branch -M main && git remote add origin https://github.com/TUO/retrofold-sp.git && git push -u origin main
  3. Settings → Pages → Deploy from branch → main → /site → il sito è online.
  4. Releases → Draft new release → allega retrofold-sp.zip (sotto) come download.
